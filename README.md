# ROS 2 C++ / CLion smoke package

A minimal `rclcpp` package used to verify the local Ubuntu, ROS 2 Lyrical, colcon, Git and CLion toolchain.

## Build from the workspace

```bash
cd ~/Projects/ros2_ws
source /opt/ros/lyrical/setup.bash
colcon build --packages-select ros2_clion_smoke
source install/setup.bash
ros2 run ros2_clion_smoke hello_node
```

Open this package directory in CLion (`~/Projects/ros2_ws/src/ros2_clion_smoke`) to edit its `CMakeLists.txt` and C++ source. The `build/`, `install/` and `log/` directories generated by colcon belong to the workspace root; they are outside this package repository and should not be committed.
